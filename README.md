# 📝 Text to PDF Converter

A simple web-based application that allows users to convert plain text into downloadable PDF files. Built with a clean separation between frontend and backend for scalability and ease of development.

## 🚀 Features

- Convert plain text to PDF
- Clean UI with responsive design
- Download the generated PDF
- API-driven backend for processing

## 🛠️ Tech Stack

### Frontend
- React.js
- TailwindCSS (or your UI library)
- Axios (for API calls)

### Backend
- Node.js
- Express.js
- `pdf-lib` / `pdfkit` or any PDF generation library
- CORS, Body-parser


---

## 🧑‍💻 Getting Started

### Prerequisites

- Node.js installed
- npm or yarn
- (Optional) VSCode for development

---

### 🔧 Setup Instructions

#### 1. Clone the Repository
```bash
git clone https://github.com/your-username/text-to-pdf-converter.git
cd text-to-pdf-converter

```
cd backend
npm install

cd ../frontend
npm install

cd backend
npm start

cd frontend
npm run dev
